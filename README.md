# CRIS · CSRI-50 性别角色探索测验

一个移动优先、零构建的 CSRI-50 自我探索网页。它展示男性化 / 女性化两个连续维度，并用传统四象限作为辅助阅读方式；群体图只使用服务器端聚合密度，不向浏览器分发逐人精确落点。

- 在线地址：<https://cochranek.github.io/cris/>
- 前端：单文件 `index.html`
- 后端：腾讯云开发 CloudBase 云函数
- 量表来源：刘电芝等（2011）《新编大学生性别角色量表揭示性别角色变迁》

## 这版重点改了什么

### 隐私与恢复

- 群体统计只保存 **0.25 分箱后的计数**，不保存逐人精确落点。
- 完整 50 题原始答案 **默认不保存到云端**。
- 只有用户主动点击“创建私人云备份”时才保存完整答案。
- 恢复密钥只存在于用户当前页面 / 私人恢复二维码中；数据库只用恢复密钥的 SHA-256 哈希作为索引。
- 分享 JSON **不包含恢复密钥**。
- 恢复链接使用 URL fragment：`#recover=<token>`，不会作为普通 HTTP 请求参数发送给服务器。
- 私人 API 明确返回 `Cache-Control: no-store, private`。
- 旧版 `?uid=` 恢复码仍可读取与删除，便于平滑迁移。

### 群体统计

群体接口不再返回 `{m,f,gender,source}` 的逐人数组，而只返回：

```json
{
  "bins": [
    {"mBin": 5.25, "fBin": 4.75, "count": 12}
  ],
  "total": 243
}
```

服务器仅在作答通过基础质量检查后把结果计入分箱统计；个人报告无论是否进入群体统计都正常生成。

### 测量学表达

- 男性化 / 女性化分数展示为两位小数，避免 `4.75 → 4.8` 造成的阈值误读。
- 阈值附近（本站用 ±0.20 作为阅读提醒）会提示“优先看连续分数”。这不是官方置信区间。
- “未分化”只作为传统分类术语，不再解释为“更自由”或“更差”。
- 不再把 CSRI-50 用作职业适配、性别认同、性取向或临床诊断工具。
- AI 开场白改为讨论沟通、决策、协作与边界表达，并明确要求区分直接测量与理论推断。

## 计分

50 题、7 点量表：

- 男性化 M：16 题，取均值
- 女性化 F：16 题，取均值
- 中性 N：18 题，不计分

本站沿用 2011 年大学生样本中位数分界：

- 双性化：M ≥ 4.80 且 F ≥ 5.00
- 男性化：M ≥ 4.80 且 F < 5.00
- 女性化：M < 4.80 且 F ≥ 5.00
- 未分化：M < 4.80 且 F < 5.00

这些分界来自 2011 年中国大学生样本，不应被描述为 2026 年一般人群常模。

## 数据流

```text
浏览器
 ├─ 本地计算个人结果
 ├─ 可选：POST /api/community/submit
 │          └─ 服务端复核计分 + 作答质量 → 只累计 0.25 分箱计数
 └─ 可选：POST /api/backup
            └─ 用户主动创建私人备份 → 保存 50 题答案

GET  /api/community  → 只返回聚合 bins
GET  /api/mine       → 需要私人恢复 token
POST /api/delete     → 删除私人可恢复备份
```

## CloudBase 集合

生产环境建议：

- `community_bins`：聚合统计
- `backups`：私人可恢复备份
- `responses`：旧版兼容集合，迁移完成后可归档 / 删除

**三个集合都必须设置为仅管理员可读写。** 浏览器只能通过云函数访问，绝不能把 `backups` 或旧 `responses` 设置成“所有人可读”。

完整部署说明见 [`cloudbase/DEPLOY.md`](cloudbase/DEPLOY.md)。

## 本地校验

无需安装依赖即可运行静态校验：

```bash
node --check cloudbase/crisApi/index.js
node tests/validate.mjs
```

CI 会检查：

- 题目总数 50，M/F/N = 16/16/18
- 前后端分类顺序一致
- 阈值一致
- JSON 导出不包含恢复 UID / token
- 恢复链接使用 fragment
- 私人 API 禁止缓存
- 群体接口不暴露逐人点

## 隐私说明

详见 [`PRIVACY.md`](PRIVACY.md)。核心原则是：

1. 最小化保存；
2. 原始答案默认仅本地；
3. 群体统计不可逆聚合；
4. 私人恢复凭证不进入分享文件；
5. 应用数据库不保存 IP，但云平台 / 网关可能产生基础访问日志，云函数也会在内存中短暂处理 IP 做限流。
